# Liang Queue Feedback

Catch what the user noticed before it slips away. Judging, planning and fixing come later.

## Contract

- **Family rules:** follow `../liang-queue-core/SKILL.md` and its `references/format.md`.
- **Their words:** keep what the user said. Add context that helps someone find the issue again later; never soften, reinterpret or solve it.
- **Quick:** the user is usually mid-flow. Write first, then report one line per item. Ask only when you cannot tell what they meant.
- **Feedback only:** write feedback items and their assets, nothing else.

## Relationship to Other Skills

- `liang-queue-add` turns feedback into a task.
- `liang-queue-tidy` closes feedback that has already been addressed.
